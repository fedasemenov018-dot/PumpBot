# 💪 PumpBot - Telegram Fitness Bot

Telegram бот для логирования тренировок и отслеживания прогресса в фитнесе.

## 📋 Возможности

- 📝 **Логирование тренировок** - записывай упражнения, вес, повторения и подходы
- 🎯 **Установка целей** - выбирай между набором массы, похудением или поддержкой формы
- 💪 **Рекомендации** - получай персональные советы в зависимости от твоей цели
- 📊 **Статистика** - отслеживай прогресс за неделю и месяц
- 🤖 **Советы от ИИ** - получай рекомендации для лучших результатов
- ⏰ **Напоминания** - настраивай напоминания о тренировках

## 🚀 Установка

### Требования
- Python 3.8+
- pip (менеджер пакетов Python)

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/fedasemenov018-dot/PumpBot.git
cd PumpBot
```

### Шаг 2: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка переменных окружения

Файл `.env` уже содержит необходимые переменные:

```
BOT_TOKEN=8895332852:AAGVYpf3SzYsv2g_2VSw7RfXjqCSXO47hVg
ADMIN_ID=8549327132
```

**Если нужно использовать собственный бот:**

1. Создай бота через [@BotFather](https://t.me/botfather) в Telegram
2. Получи токен бота
3. Замени значение `BOT_TOKEN` в файле `.env` на твой токен
4. Свой ID можно узнать через [@userinfobot](https://t.me/userinfobot)

### Шаг 4: Запуск бота

```bash
python main.py
```

Бот начнёт работать и будет готов к использованию!

## 📖 Использование

После запуска бота откройте его в Telegram и используйте следующие команды:

### Основные команды

- `/start` - Запуск бота и главное меню
- `/help` - Справка по всем функциям
- `/cancel` - Отмена текущей операции

### Функции бота

#### 📝 Логировать тренировку
1. Выбери "📝 Логировать тренировку" в меню
2. Введи название упражнения (например: жим лежа)
3. Укажи вес в килограммах
4. Введи количество повторений
5. Укажи количество подходов
6. Готово! Тренировка залогирована ✅

#### 🎯 Установить цель
1. Выбери "🎯 Установить цель"
2. Выбери один из вариантов:
   - 💪 Набрать массу
   - 🏃 Похудеть
   - ⚖️ Поддержать форму
3. Бот даст рекомендации для твоей цели

#### 💪 Рекомендации
Получи советы по тренировкам:
- Разминка
- Отдых между подходами
- Прогрессия нагрузки
- Частота тренировок
- Растяжка

#### 📊 Статистика
Посмотри свой прогресс:
- Количество тренировок за неделю/месяц
- Среднее поднятое количество веса
- Лучшие упражнения
- Общий прогресс

#### 🤖 Совет от ИИ
Получи персональный совет для лучших результатов:
- Регулярность тренировок
- Прогрессия веса
- Восстановление и сон
- Питание и калорийность
- Отслеживание прогресса

## 🐛 Решение проблем

### Ошибка: "TELEGRAM_BOT_TOKEN не установлен"
- Проверь, что файл `.env` существует в папке проекта
- Убедись, что в `.env` правильно указан токен бота

### Ошибка: "ModuleNotFoundError: No module named 'telegram'"
- Установи зависимости: `pip install -r requirements.txt`

### Бот не отвечает
- Проверь интернет-соединение
- Убедись, что токен бота правильный
- Перезапусти бота: останови (Ctrl+C) и запусти снова
